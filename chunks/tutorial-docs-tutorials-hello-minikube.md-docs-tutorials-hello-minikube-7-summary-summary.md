## Open the Dashboard
Open the Kubernetes dashboard. You can do this two different ways:
Open a **new** terminal, and run:
```
`# Start a new terminal, and leave this running.
minikube dashboard
`
```
Now, switch back to the terminal where you ran `minikube start`.
