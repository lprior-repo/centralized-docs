# kubectl run
Run a particular image on the cluster
## Synopsis
Create and run a particular image in a pod.
```
`kubectl run NAME --image=image [--env="key=value"] [--port=port] [--dry-run=server|client] [--overrides=inline-json] [--command] -- [COMMAND] [args...]
`
```
