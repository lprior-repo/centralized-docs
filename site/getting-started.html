Get Started with llms.txt

Add llms.txt to your documentation in 3 simple steps.

1. Copy Example

Start with a validated example:

cp examples/rust-llms.txt llms.txt

Or use another example from the Examples page.

2. Edit for Your Project

Update the YAML frontmatter and content:

  • Change project to your project name
  • Update url to your project's base URL
  • Set updated to today's date
  • Adjust sections and links to match your documentation
3. Validate and Deploy

Validate your file before deployment:

llms-txt validate ./llms.txt

If validation passes, commit and push:

git add llms.txt
git commit -m "Add llms.txt for AI discovery"
git push
