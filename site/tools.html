llms.txt Tools

🔍 llms-txt-validator

CLI tool for validating llms.txt files against RFC specification.

Features:

  • Validate YAML frontmatter
  • Check required sections
  • Verify link format
  • Enforce file size limits

Usage:

llms-txt validate ./llms.txt

Source: doc_transformer/src/bin/llms_txt_validator.rs

📖 llms-txt-parser

Rust library for parsing llms.txt files programmatically.

Features:

  • Parse YAML frontmatter
  • Extract sections and links
  • Validate structure
  • Serialize/Deserialize support

Usage:

use llms_txt_parser::parse_content;
let llms_txt = parse_content(content)?;

Source: llms-txt-parser/

🔧 doc_transformer

CLI tool for generating llms.txt from documentation.

Features:

  • Auto-generate llms.txt from docs
  • Smart section detection
  • YAML frontmatter with metadata
  • Support for multiple doc formats

Usage:

doc_transformer index ./docs --output ./indexed

Source: doc_transformer/
