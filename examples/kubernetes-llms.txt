# Kubernetes

> Production-Grade Container Orchestration

Kubernetes is an open-source system for automating deployment, scaling, and management of containerized applications. It groups containers that make up an application into logical units for easy management and discovery.

## Getting Started

- [What is Kubernetes?](https://kubernetes.io/docs/concepts/overview/what-is-kubernetes/): Understand Kubernetes fundamentals
- [Installation](https://kubernetes.io/docs/setup/): Install Kubernetes on your platform
- [Tutorial](https://kubernetes.io/docs/tutorials/): Step-by-step tutorials
- [Hello Minikube](https://kubernetes.io/docs/tutorials/hello-minikube/): Run a local Kubernetes cluster

## Core Concepts

- [Pods](https://kubernetes.io/docs/concepts/workloads/pods/): The smallest deployable units
- [Services](https://kubernetes.io/docs/concepts/services-networking/service/): Expose applications
- [Deployments](https://kubernetes.io/docs/concepts/workloads/controllers/deployment/): Update applications declaratively
- [ConfigMaps](https://kubernetes.io/docs/concepts/configuration/configmap/): Configure applications
- [Volumes](https://kubernetes.io/docs/concepts/storage/volumes/): Store data persistently
