# Rust Programming Language

> A language empowering everyone to build reliable and efficient software.

Rust is a systems programming language focused on safety, speed, and concurrency. This documentation helps you learn Rust, understand its core concepts, and build production systems.

## Getting Started

- [Installation](https://doc.rust-lang.org/book/ch00-00-introduction.html): Install Rust using rustup
- [Hello World](https://doc.rust-lang.org/rust-by-example/hello.html): Write your first Rust program
- [Cargo Basics](https://doc.rust-lang.org/cargo/guide/): Learn Rust's build system and package manager
- [Common Concepts](https://doc.rust-lang.org/book/ch02-00-guessing-game-tutorial.html): Variables, types, functions, and control flow

## Core Concepts

- [Ownership](https://doc.rust-lang.org/book/ch04-00-understanding-ownership.html): Understand memory safety without garbage collection
- [Borrowing](https://doc.rust-lang.org/book/ch04-02-references-and-borrowing.html): References and lifetimes explained
- [Error Handling](https://doc.rust-lang.org/book/ch09-00-error-handling.html): Result and Option types for robust code
- [Traits](https://doc.rust-lang.org/book/ch10-00-generics.html): Shared behavior and polymorphism
- [Generics](https://doc.rust-lang.org/book/ch10-00-generics.html): Write flexible, reusable code

## API Reference

- [Standard Library](https://doc.rust-lang.org/std/): Complete standard library reference
- [Collections](https://doc.rust-lang.org/std/collections/index.html): Vec, HashMap, HashSet, and more
- [I/O](https://doc.rust-lang.org/std/io/index.html): File and network operations
- [Concurrency](https://doc.rust-lang.org/std/sync/index.html): Threads, channels, and synchronization

## Operations

- [Deployment](https://doc.rust-lang.org/book/ch12-00-an-io-project.html): Ship Rust binaries to production
- [Performance](https://doc.rust-lang.org/nomicon/perf.html): Profiling and optimization techniques
- [Troubleshooting](https://doc.rust-lang.org/error-index.html): Common errors and solutions

## Advanced Topics

- [Unsafe Rust](https://doc.rust-lang.org/nomicon/intro.html): Low-level control when needed
- [Macros](https://doc.rust-lang.org/book/ch19-00-macros.html): Code generation and metaprogramming
- [Async/Await](https://rust-lang.github.io/async-book/): Asynchronous programming patterns
