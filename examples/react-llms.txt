# React

> The library for web and native user interfaces

React is a JavaScript library for building user interfaces. It lets you compose complex UIs from small and isolated pieces of code called "components".

## Getting Started

- [Installation](https://react.dev/learn/installation): Set up a new React project
- [Quick Start](https://react.dev/learn): Learn React fundamentals
- [Thinking in React](https://react.dev/learn/thinking-in-react): Understand React's approach
- [Your First Component](https://react.dev/learn/your-first-component): Create your first React component

## Core Concepts

- [Components](https://react.dev/learn/your-first-component): Building blocks of React UIs
- [JSX](https://react.dev/learn/writing-markup-with-jsx): Writing HTML-like code in JavaScript
- [Props](https://react.dev/learn/passing-props-to-a-component): Passing data to components
- [State](https://react.dev/learn/state-a-components-memory): Managing component state
- [Events](https://react.dev/learn/responding-to-events): Handling user interactions
