# Data in transit encryption in Step Functions
Step Functions encrypts data in transit between the service and other integrated AWS
services (see [Integrating services with Step Functions](./integrate-services.html)). All data that passes between
Step Functions and integrated services is encrypted using Transport Layer Security
(TLS).
