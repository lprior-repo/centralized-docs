### Caution
Use `{{&lt; caution &gt;}}` to call attention to an important piece of information to avoid pitfalls.
For example:
```
`{{&lt; caution &gt;}}
The callout style only applies to the line directly above the tag.
{{&lt; /caution &gt;}}
`
```
The output is:
#### Caution:
The callout style only applies to the line directly above the tag.
