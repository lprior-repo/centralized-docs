# Концепции
Раздел "Концепции" поможет вам узнать о частях системы Kubernetes и об абстракциях, которые Kubernetes использует для представления вашего [кластера](/ru/docs/reference/glossary/?all=true#term-cluster), и помогает вам глубже понять, как работает Kubernetes.
