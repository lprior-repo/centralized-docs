# Graph Subcommand - Knowledge DAG Traversal


## Overview

The knowledge graph is a Directed Acyclic Graph (DAG) that represents:
- **Documents** as nodes
- **Chunks** (semantic sections) as nodes
- **Relationships** as weighted edges between nodes
