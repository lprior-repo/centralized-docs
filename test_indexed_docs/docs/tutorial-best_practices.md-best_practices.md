# Best Practices for llms.txt



 > 
 > **Context**: Create effective `llms.txt` files for AI agents:



Create effective `llms.txt` files for AI agents:

1. **Short Descriptions:** One sentence per link.
1. **Logical Sections:** Group by `Getting Started`, `Core Concepts`, `API Reference`.
1. **Progressive Complexity:** Simple to complex order.
1. **Metadata:** Always include `llms_version`, `project`, `url`, `updated`.
1. **Curation:** Don’t put everything in `llms.txt`. Link to smaller files instead.
