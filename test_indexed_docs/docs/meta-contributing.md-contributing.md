# Contributing



 > 
 > **Context**: Thank you for your interest in contributing to the llms.txt standard!



Thank you for your interest in contributing to the llms.txt standard!

## Ways to Contribute

1. **Submit Examples**: Add `llms.txt` examples from popular projects to the `examples/` directory. Ensure they pass the validator.
1. **Report Bugs**: Use GitHub Issues to report bugs with steps to reproduce.
1. **Propose RFC Changes**: Open a GitHub Discussion for proposed changes.
1. **Improve Tools**: Contribute to the validator (`doc_transformer`) or parser (`llms-txt-parser`).
1. **Documentation**: Help improve existing docs or translations.

## Development Workflow

* Fork the repository.
* Create a feature branch.
* Make changes following Rust guidelines.
* Test your changes: `moon run :test`, `:clippy`, `:fmt`.
* Submit a PR.

## Code of Conduct

We expect all contributors to maintain a positive, inclusive, and respectful environment.
