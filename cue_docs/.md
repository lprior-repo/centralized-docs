CUE INTEGRATIONS

CUE works with a wide range of tools and formats that you're already using ...


GO

Read about how CUE’s Go API brings its power and flexibility into your
programs, and lets you convert Go types to CUE schemas.
Learn more

Learn more [/docs/concept/how-cue-works-with-go/]


JSON

CUE might look a bit like JSON, but that’s where the similarity ends.
Discover how CUE helps you tame your static JSON data files.
Learn more

Learn more [/docs/concept/how-cue-works-with-json/]


YAML

Love YAML’s “anchors”? No.
No, you don’t - no-one does … and for good reason!
Learn about how CUE reads and writes YAML, whilst delivering a much better
referencing system!
Learn more

Learn more [/docs/concept/how-cue-works-with-yaml/]


OPENAPI

CUE has first class support for OpenAPI’s data schemas, using them to validate data directly.
See how CUE makes OpenAPI easier to handle and understand.
Learn more

Learn more [/docs/concept/how-cue-works-with-openapi/]


JSON SCHEMA

JSON Schema can be used as if it were CUE - and can be converted to CUE just as easily.
Find out more about CUE’s native support for JSON Schema.
Learn more

Learn more [/docs/concept/how-cue-works-with-json-schema/]


PROTOCOL BUFFERS

CUE understands Protocol Buffers, extending Protobuf’s capabilities
by validating data values and not just the data schema.

Learn more

Learn more [/docs/concept/how-cue-works-with-protocol-buffers/]
