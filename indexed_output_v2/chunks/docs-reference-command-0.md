 2. THE CUE COMMAND

The cue command is a versatile interface for working with CUE and its ecosystem.
It provides a variety of sub-commands, including tools
for validating [/docs/reference/command/cue-help-vet/],
importing [/docs/reference/command/cue-help-import/], and
exporting [/docs/reference/command/cue-export/] data and constraints;
for creating
data-driven workflows [/docs/reference/command/cue-help-commands/];
and for working with dependencies via
CUE modules [/docs/reference/command/cue-help-modules/] and
module registries [/docs/reference/command/cue-help-registryconfig/].

On this page you can find the full list of sub-commands [/docs/reference/command/#help-texts]
in the latest version of cue, and their built-in help texts.
You’ll also find an incomplete-but-expanding set of guides dedicated to
the most commonly-used sub-commands [/docs/reference/command/#guides].
These guides include curated links to related content, including how-to guides,
tutorials and other relevant documentation.

THE CUE EXPORT COMMAND

Use cue export to produce validated, concrete data for tools that need
configurations encoded in formats like JSON or YAML.
