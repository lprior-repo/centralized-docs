# Best Practices for llms.txt

Create effective `llms.txt` files for AI agents:

1. **Short Descriptions:** One sentence per link.
2. **Logical Sections:** Group by `Getting Started`, `Core Concepts`, `API Reference`.
3. **Progressive Complexity:** Simple to complex order.
4. **Metadata:** Always include `llms_version`, `project`, `url`, `updated`.
5. **Curation:** Don't put everything in `llms.txt`. Link to smaller files instead.
