# Setting Up a PowerShell Development Environment
Lambda provides a set of tools and libraries for the PowerShell runtime. For installation instructions, see
[Lambda tools for PowerShell](https://github.com/aws/aws-lambda-dotnet/tree/master/PowerShell) on GitHub.
The AWSLambdaPSCore module includes the following cmdlets to help author and publish PowerShell Lambda
functions:
* **Get-AWSPowerShellLambdaTemplate** – Returns a list of getting started
templates.
* **New-AWSPowerShellLambda** – Creates an initial PowerShell script based
on a template.
* **Publish-AWSPowerShellLambda** – Publishes a given PowerShell script to
Lambda.
* **New-AWSPowerShellLambdaPackage** – Creates a Lambda deployment package
that you can use in a CI/CD system for deployment.
