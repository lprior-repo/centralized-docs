# TracingConfig
The function's [AWS X-Ray](https://docs.aws.amazon.com/lambda/latest/dg/services-xray.html) tracing configuration.
To sample and record incoming requests, set `Mode` to `Active`.
## Contents
**
Mode
**
The tracing mode.
Type: String
Valid Values: `Active | PassThrough`
Required: No
