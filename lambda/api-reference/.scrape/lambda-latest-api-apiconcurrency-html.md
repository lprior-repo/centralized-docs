ReservedConcurrentExecutions
**
The number of concurrent executions that are reserved for this function. For more information, see [Managing Lambda reserved
concurrency](https://docs.aws.amazon.com/lambda/latest/dg/configuration-concurrency.html).
Type: Integer
Valid Range: Minimum value of 0.
Required: No
